# AutoClip

A polished, responsive YouTube auto-clipper website prototype.

## Demo

The default video is:

https://www.youtube.com/watch?v=irNhWMG560k

## Run locally

Open `index.html` directly in a browser, or serve the directory:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Features

- YouTube URL loading
- Embedded video preview
- 9:16, 1:1, and 16:9 format controls
- Clip-length and caption controls
- Animated clip-generation state
- Responsive desktop and mobile layouts

The current version is a frontend prototype. It does not download or process YouTube media.
